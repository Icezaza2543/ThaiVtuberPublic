การใช้งานที่อนุญาต

ใช้เพื่อค้นหา อ้างอิง และทำความเข้าใจข้อมูลสาธารณะตามการทำงานปกติของเว็บไซต์ได้ ภายใต้ license ที่ระบุ

การใช้งานที่ห้าม

  • bulk extraction หรือการดาวน์โหลดฐานข้อมูลเป็นชุด
  • automated scraping หรือ enumeration เพื่อสร้างฐานข้อมูลขึ้นใหม่
  • dataset mirroring หรือ redistribution ของ compiled dataset
  • หลบเลี่ยง rate limit, access control, bot challenge หรือมาตรการป้องกัน
  • ใช้ bot ที่สร้างภาระหรือรบกวนบริการ
  • พยายาม re-identify ผู้ส่งข้อมูล private intake
  • ทดสอบทำลายระบบโดยไม่ได้รับอนุญาต

API และระบบอัตโนมัติ

API สาธารณะมีไว้รองรับ UI แบบ bounded access ไม่ใช่ bulk data interface การเข้าถึงด้วยระบบอัตโนมัติต้องไม่พยายามหลบข้อจำกัดของบริการ

การบังคับใช้

เราอาจจำกัด challenge หรือ block traffic ที่มีรูปแบบผิดปกติหรือขัดกับข้อกำหนด โดยพยายามไม่กระทบผู้ใช้ทั่วไปและ search engine ที่ถูกต้อง
