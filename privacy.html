Privacy Policy

มีผลตั้งแต่ 5 ตุลาคม 2026

หลักการ Data Minimization

VThaiDex ตั้งใจเก็บข้อมูลส่วนบุคคลของผู้ใช้ให้น้อยที่สุด หน้า contribution ไม่ขอชื่อผู้แจ้ง อีเมล บัญชี social หรือ login identity

ข้อมูลสาธารณะที่แสดง

สารบบแสดงเฉพาะ public projection ของข้อมูล VTuber เช่นชื่อ สังกัด lifecycle ปีเดบิวต์ที่ทราบ และลิงก์บัญชีสาธารณะที่ผ่านการจัดระเบียบ

Private contribution

เมื่อระบบรับข้อมูลเปิดใช้งาน ข้อมูลฟอร์มจะถูกเข้ารหัสใน browser ก่อนส่ง เซิร์ฟเวอร์จัดเก็บ ciphertext และไม่มี private key สำหรับถอดข้อมูลนั้น

สิ่งที่ application ไม่ตั้งใจเก็บ

intake record จะไม่คัดลอก IP address, User-Agent, Referer, cookie, ชื่อผู้แจ้ง หรือข้อมูลติดต่อไปเก็บเป็น application data และไม่เก็บ draft ลง localStorage/sessionStorage

Infrastructure metadata

ผู้ให้บริการ hosting, CDN, network หรือ ISP อาจประมวลผล request metadata ตามการทำงานของโครงสร้างพื้นฐาน VThaiDex จึงไม่อ้างว่าการส่งข้อมูล anonymous 100%

Retention

encrypted intake ที่ pending มีเป้าหมาย retention 60 วัน ส่วน reviewed/rejected 7 วัน หลังจากนั้นจะถูก purge ตามนโยบายระบบ

Bot challenge

หากมี abuse สูง อาจใช้ adaptive human-verification challenge สำหรับ traffic ที่น่าสงสัยเท่านั้น หากเปิดใช้ provider เพิ่มเติม หน้านี้จะระบุ provider และวัตถุประสงค์ โดยจะไม่ส่ง plaintext form body ให้ challenge provider

Security limitations

client-side encryption ลดผลกระทบเมื่อ storage หลุด แต่ไม่สามารถป้องกัน malware บนอุปกรณ์ผู้ส่ง หรือ frontend ที่ถูก attacker ยึดและแก้ไขก่อนการเข้ารหัสได้
